# 매일 활동 기록 — DB 저장 구조 & 스펙

> 작성: 2026-06-04 · 대상: `app/dashboard/activities/new`
> 배경: 클라이언트 임시저장 → **DB 영속화**로 전환(기기 변경·관리자의 원아별 히스토리 조회).

---

## 1. 저장 위치 (무엇이 어디에)

| 데이터 | 테이블/스토리지 | 컬럼 |
|---|---|---|
| 활동 세션(반+날짜) | `activity_sessions` | `title`(활동명), `date`, `classroom_id`, `created_by` |
| **1단계 AI 활동 분석** | `activity_records` | **`session_ai_content`**(제목+내역+키워드+추천) · `session_ai_generated_at` |
| 사진별 활동 태그 | `activity_records` | `memo` |
| **2단계 원아별 활동 메모** | `activity_records` | **`ai_content`** · `ai_generated_at` *(컬럼만 준비 — 저장 기능은 2단계 작업자 구현)* |
| 원아별 사진(메타) | `child_activity_photos` → `files` | `file_id`, `order_num` |
| 사진 원본 | Supabase Storage `child-photos` | `{kindergarten_id}/{child_id}/{uuid}.jpg` |

- `activity_records`는 **(session_id, child_id) 당 1행** (UNIQUE). 원아별 히스토리는 child_id로 조회.
- 저장 트리거: **1단계 "저장하기"** → 세션·사진·`session_ai_content` (이번 작업 범위).
- **2단계 원아별 메모 저장은 2단계(원아 활동 기록) 작업자 담당**입니다. 저장 대상 컬럼만 준비돼 있음: `activity_records.ai_content` (+`ai_generated_at`), (session_id, child_id) upsert. 1단계 저장으로 세션이 먼저 생성돼 있어야 함.

> 이전 이슈: 사진만 저장되고 활동 분석이 누락 → **1단계 `session_ai_content` 저장 추가로 해결**. (2단계 `ai_content`는 컬럼 준비 상태)

---

## 2. 저장 스펙 (인당 기준)

| 항목 | 기준 |
|---|---|
| **원아당 하루 사진** | **최대 6장** (서버 저장 시 초과분 절삭) |
| 사진 규격 | 1280px 리사이즈 · JPEG 품질 0.82 → 장당 평균 ~200KB |
| 텍스트(분석·메모) | **제한 없음** (원아당 하루 ~1KB, 무시 가능) |
| 업로드 세션 1회 | 최대 100장(반 전체 합산) |

### 용량 추정 (유치원 50명, 반 15~20명, 연 ~240일)
| 기준 | 인당/년 | 50명/년 |
|---|---|---|
| 6장/일 × 200KB | ~290MB | **~14GB** |

→ Supabase Pro(100GB) 기준 **수년 운용 가능**. (텍스트는 DB라 용량 영향 미미)

---

## 3. 보관 정책

- **사진**: **재원 기간 전체 + 졸업/퇴소 후 1년** 보관 → 이후 정리(삭제).
- **텍스트(활동 분석·메모)**: **제한 없이 보관**(용량 부담 없음, 히스토리 가치).

### 정리(삭제) 실행 — 후속 작업 필요
자동 삭제는 **스케줄 작업(cron)** 이 필요합니다(현재 미구현). 대상 식별 기준:
- `children.status in ('graduated','inactive')` 이고 `child_classroom_history.ended_at`(또는 status 변경일) **+1년 경과**.
- 해당 원아의 `child_activity_photos` → `files` → Storage 객체 삭제 + 행 삭제. (텍스트 `activity_records`는 유지)

> ⚠️ 삭제는 비가역이므로, 실제 구현 시 **드라이런(대상 목록 출력) → 확인 → 삭제** 순서를 권장. 스케줄러(예: Supabase cron / 외부 잡)에서 월 1회 실행.
